# Maze

A Python maze game built with Tkinter. Find the exit while exploring in the dark, then compare your route with the shortest path.

- Random mazes generated with depth-first search
- Arrow keys or WASD to move
- Difficulty presets and custom settings
- Shortest paths found with bfs
- Stats for each difficulty during the session

Requires Python 3.12+ with Tkinter.

Run the game:

```bash
python3 app.py
```
